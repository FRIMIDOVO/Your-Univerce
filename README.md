# 🌌 Your Universe

**Физическая симуляция частиц на собственном движке с визуализацией.**

---

## Возможности

- **До 1 000 000 частиц** на CPU
- **Гексагональная сетка (HexGrid)** для оптимизации
- **Законы физики**: инерция, гравитация, упругие столкновения, трение, липкость
- **Визуализация**: SFML, цвет частиц по массе, векторы скорости
- **Экспорт кадров** в PNG для создания GIF/MP4
- **Гибкая настройка**: все параметры в текстовых конфигах

## Как это работает

1. В пространстве создаются частицы со случайными свойствами.
2. С каждым шагом `dt` применяются законы физики.
3. После расчётов — визуализация через SFML.
4. Все параметры вынесены в txt-файлы, чтобы менять физику без перекомпиляции.

## Производительность

| Частиц | Время шага | FPS |
|--------|------------|-----|
| 1 000  | ~2 ms      | 500 |
| 10 000 | ~8 ms      | 125 |
| 100 000| ~35 ms     | 28  |
| 1 000 000| ~150 ms  | 6   |

> На CPU без GPU!

## Сборка
Для сборки потребуется установить SFML и поменять пути к папкам в `build.bat`
